# 유튜브 자동 편집

영상을 올리면 대본을 바탕으로 1차 컷 편집을 하고, MZ 말투 자막과 일러스트, 예능 효과를 넣고, 개인정보를 가리는 로컬 웹 프로그램입니다.

## 실행

1. `install.bat`을 실행합니다. 처음 한 번만 하면 됩니다.
2. `start.bat`을 실행하면 브라우저에 `http://127.0.0.1:8766`이 열립니다.
3. 설정 칸에 Claude·OpenAI API 키를 넣고 저장합니다.
4. 영상을 끌어다 놓고 **전체 실행**을 누릅니다.

`install.bat`은 없는 것만 설치합니다: Python 3.12, ffmpeg, Visual C++ 런타임, 파이썬 패키지. 처음 실행할 때 음성인식 모델(약 1.6GB)을 내려받습니다.

프로그램을 켜 둔 상태에서 코드가 바뀌면 알아서 다시 시작하고 화면도 새로고침합니다. 다시 실행할 필요가 없습니다.

- 전사나 렌더가 도는 중이면 끝난 뒤에 적용합니다.
- 기획을 수정하던 중이거나, 영상을 재생하는 중이거나, API 키를 입력하는 중이면 화면 새로고침을 미룹니다.
- `requirements.txt`가 바뀌었을 때만 `install.bat`을 다시 실행합니다.

## 걸리는 시간

이 PC(Core Ultra 5 225H, NVIDIA GPU 없음)에서 잰 값입니다.

| 단계 | 속도 |
|---|---|
| 전사 (large-v3-turbo) | 재생 시간의 약 40% |
| 컷 편집본 렌더 | 재생 시간의 약 10% |
| 개인정보 탐지 | 화면이 바뀐 샘플 하나에 약 1.5초. 화면이 계속 바뀌면 재생 시간의 약 3배까지 걸립니다. 마우스나 웹캠만 움직이면 훨씬 빠릅니다. |
| 최종 렌더 | 재생 시간의 약 35% |
| 그림 생성 | 최대 8장을 동시에 만듭니다. 실제 호출에서 아이콘 약 13초, 일러스트 약 28초가 걸렸습니다. |

OpenAI 계정 등급의 요청 한도에 걸리면 기다렸다가 다시 보내므로 그림이 빠지지는 않지만, 그만큼 시간이 늘어납니다.

오래 걸리면 **세부 조절**에서 OCR 간격을 늘릴 수 있습니다. 대신 빠르게 지나가는 개인정보를 놓칠 위험이 커집니다.

## 처리 순서

| 단계 | 하는 일 | 필요한 것 |
|---|---|---|
| 전사 | OpenAI `whisper-1`로 단어별 시각까지 받아쓰기 | OpenAI 키, 없거나 실패하면 이 PC의 Whisper |
| 컷 편집 | 무음·추임새·말더듬 제거 | 없음 (언어 모델 키가 있으면 문맥 검토 추가) |
| 자막 | 읽기 좋게 나누고 MZ 말투로 변환. 외국어 영상은 한국어로 번역 | 언어 모델 키 |
| 기획 | 일러스트, 로고·아이콘, 예능 효과의 위치와 내용 결정 | 언어 모델 키 |
| 이미지 생성 | 플랫 벡터 + 핸드드로잉 카툰풍 그림 생성 | OpenAI 키, 없으면 Claude 키(SVG) |
| 개인정보 탐지 | 화면 OCR과 얼굴·음성 탐지, 사람 위치 찾기 | 없음 |
| 최종 렌더 | 원본에 모자이크, 효과, 그림, 자막을 합성하고 효과음을 입힘 | 없음 |

언어 모델은 Claude를 먼저 쓰고, 키나 크레딧이 없으면 OpenAI로 대신합니다. OpenAI 키 하나만 있어도 전부 동작합니다. 키가 하나도 없어도 컷 편집, 모자이크, 렌더는 동작합니다.

전사 모델 `whisper-1`은 OpenAI 공지상 2027년 2월 26일 종료 예정입니다. 다른 OpenAI 전사 모델은 컷 편집에 필요한 단어별 시각을 주지 않아서, 그 뒤에는 옵션의 **전사**를 **이 PC**로 바꿔야 합니다.

언어 모델 호출이 실패해도(크레딧 부족 등) 편집은 끝까지 진행됩니다.

- 기획이 실패하면 그림과 효과 없이 완성합니다. 원인을 해결하고 **전체 실행**을 누르면 기획부터 다시 합니다.
- 자막 말투 변환이 실패하면 전사 내용을 그대로 자막으로 씁니다.
- 컷 문맥 검토가 실패하면 규칙으로만 자르고 리포트에 남깁니다. 나중에 검토를 받으려면 **컷 편집** 단계를 강제 재실행합니다.
- **기획 수정** 탭에서 일러스트를 직접 추가하고 프롬프트를 쓰면 Claude 없이도 그림을 넣을 수 있습니다. 직접 수정한 기획은 **기획** 단계를 강제 재실행할 때만 교체됩니다.

옵션을 바꾸고 다시 실행하면 영향받는 단계만 돌아갑니다. 영상 카드의 칩은 초록색이 완료, 주황색이 옵션이 바뀌어 다시 실행이 필요한 상태입니다.

## 컷 편집 기준

말을 잘못 자르는 손해가 무음을 남기는 손해보다 크다고 보고 설계했습니다.

- 작게 말한 단어는 무음으로 보지 않습니다.
- `이 이미지를`, `그 그림은`처럼 정상적인 표현은 더듬음으로 보지 않습니다.
- `네 네`, `천천히 천천히` 같은 강조 반복은 남깁니다.
- `그`, `이제`, `막`처럼 뜻이 있을 수도 있는 말은 Claude 키가 있을 때만 문맥을 보고 판단합니다.
- 모든 컷은 **기획 수정** 탭에서 되살릴 수 있고, **대본** 탭에서 지워진 말을 빨간 취소선으로 볼 수 있습니다.

## 자막

전사 내용을 한 줄 22자 안팎으로 나누고 MZ 말투로 바꿔 영상에 입힙니다. SRT 파일에도 같은 내용이 들어갑니다. 뜻, 숫자, 고유명사는 바꾸지 않도록 지시하지만, **기획 수정** 탭에서 원래 말과 나란히 보면서 고칠 수 있습니다.

영어로 말하는 영상은 옵션의 **말하는 언어**를 **영어**로 바꿔 주세요. 영어로 받아쓴 뒤 자막을 한국어(MZ 말투 옵션이 켜져 있으면 MZ 말투)로 옮깁니다. 한국어로 둔 채 영어 영상을 넣으면 받아쓰기가 영어를 멋대로 한국어로 바꾸면서 말을 빠뜨립니다. **자동 감지**는 한 영상에 언어가 섞이면 틀리게 고를 수 있습니다.

## 예능 효과

**예능 효과** 옵션에서 고릅니다. 방송의 로고, 글꼴, 음원은 쓰지 않고 편집 문법만 따르며, 효과음은 프로그램이 직접 합성합니다.

| 스타일 | 효과 |
|---|---|
| 무한도전풍 | 화면 확대, 흔들림, 집중선, 정지 화면, 큰 컬러 자막 |
| 흑백요리사풍 | 흑백 긴장감, 천천히 확대, 묵직한 타이틀 카드, 화면 확대 |
| 섞어서 | 위 효과를 모두 사용 |

어디에 어떤 효과를 넣을지는 언어 모델이 대본을 보고 정합니다. **기획 수정** 탭에서 효과와 효과음을 바꾸거나 직접 추가할 수 있습니다.

## 아이콘 배치

영상에서 얼굴을 찾아 사람이 있는 영역을 추정합니다. 로고·아이콘과 큰 자막은 그 영역과 아래쪽 자막 자리를 피해 위치를 바꾸고, 자리가 없으면 크기를 줄입니다. 옆에 붙는 일러스트 카드도 같습니다. **중앙 카드**와 **전체 화면**은 일부러 화면을 덮는 방식이라 움직이지 않습니다. 얼굴이 보이지 않는 사람은 찾지 못합니다.

## 개인정보 탐지 범위

- 형식으로 찾는 항목: 이메일, 전화번호, 주민등록번호, 카드번호, 사업자등록번호, API 키, 주소
- 항목명이 있어야 찾는 항목: `이름:`, `주소:`, `예금주`, `비밀번호:`, `계좌` 뒤의 값
- 연락처 바로 앞의 이름: `김철수 010-1234-5678`처럼 붙어 있으면 이름도 가립니다.
- 그 밖에 문장 속에 나오는 사람 이름은 형식만으로 찾을 수 없습니다. **이름·주소를 Claude로 추가 판별** 옵션을 켜면 찾을 수 있지만, 화면 글자가 Claude API로 전송됩니다.
- 움직이는 글자는 샘플 사이의 경로를 통째로 가려서, 스크롤하는 동안 모자이크가 글자보다 넓게 보입니다.
- 자막에 전화번호나 이메일 같은 형식이 나오면 `●●●`로 바꿉니다. 음성 음소거 구간의 자막은 `(삐-)`로 나옵니다.

**자동 탐지는 놓칠 수 있습니다.** 공개 전에 반드시 **기획 수정 → 개인정보 모자이크** 목록과 최종 영상을 직접 확인하고, 놓친 부분은 **직접 추가**로 가려 주세요.

## 외부로 전송되는 데이터

- **전사**가 OpenAI API이면 영상의 음성이 OpenAI로 전송됩니다. **이 PC**로 바꾸면 전송되지 않습니다.
- 대본(전사문)이 Claude 또는 OpenAI API로 전송됩니다. 자막 말투 변환, 기획, 문맥 검토에 쓰입니다.
- 이미지 프롬프트가 OpenAI API로 전송됩니다.
- 영상 화면은 전송되지 않습니다. 단, **이름·주소를 AI로 추가 판별**을 켜면 화면에서 읽은 글자가 전송됩니다.

## 로고

`assets/logos/`에 로고 이미지를 넣으면 기획에 자동으로 쓰입니다. 파일명에 서비스 이름을 넣어 주세요. 예: `스레드_Threads_로고.png`. 폴더에 없는 로고는 그림으로 지어내지 않습니다.

## 개발

```bash
.venv\Scripts\python -m pytest tests
```

```bash
.venv\Scripts\python -m tests.make_sample
```

`tests/verify_sample.py`는 `samples/test_video.mp4`의 완성본을 다시 전사하고 OCR해서, 말이 사라지지 않았는지와 개인정보가 보이지 않는지를 검사합니다.

```bash
.venv\Scripts\python -m tests.verify_sample
```

`tests/mock_apis.py`는 API 키 없이 Claude·OpenAI 경로를 시험하는 가짜 서버입니다. `ANTHROPIC_BASE_URL`과 `OPENAI_BASE_URL`을 이 서버로 지정해 씁니다.

사용 모델은 환경 변수 `CLAUDE_MODEL`(기본 `claude-opus-5-5`), `OPENAI_TEXT_MODEL`(기본 `gpt-5.4-mini`), `OPENAI_TRANSCRIBE_MODEL`(기본 `whisper-1`), `OPENAI_IMAGE_MODEL`로 바꿀 수 있습니다.
